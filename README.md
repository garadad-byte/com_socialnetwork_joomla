# Social Network for Joomla 5/6

This repository contains a staged implementation of a Google+-inspired social network component for Joomla 5/6.

## Stage 1: Project skeleton
- installable Joomla package scaffold
- admin dashboard and ACL foundation
- frontend feed and profile shell
- SQL schema and migration foundation

## Stage 2: Social graph
- profiles
- circles
- communities
- relationship/follow logic
- AJAX follow interaction

## Stage 3: Live social stream
- posts
- optional links
- hashtags
- comments
- +1 reactions
- AJAX publishing and commenting

## Stage 4: Communication and moderation
- notifications
- private messages
- events and invitations
- search
- reports and blocks
- moderation flows and lists

## Stage 5: Privacy, invitations, media and link preview
This stage adds:
- privacy settings management
- invitation workflows
- media upload handling
- link metadata preview for shared urls
- navigation additions for privacy, invitations and media

This keeps the project in a consistent, installable state while extending the feature set toward a complete social network.
